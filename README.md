# 💌 Surat Cinta Abadi • Melodi & Romansa Jiwa

Program web surat cinta interaktif dengan nuansa asmara yang memukau, dilengkapi alunan musik piano romantis, kelopak mawar berguguran, amplop segel lilin 3D, galeri polaroid, dan untaian kata-kata asmara yang mendalam.

---

## ✨ Fitur Unggulan

1. **Amplop 3D & Segel Lilin (*Wax Seal*)**:
   - Amplop mewah dengan pita sutra emas dan segel lilin merah berembos hati.
   - Sentuh segel lilin untuk memecahkannya dengan efek suara realistis, percikan partikel emas, dan pembukaan lembaran surat.

2. **Sistem Musik Romantis (Web Audio API Synthesizer)**:
   - **Piano Akustik Balada (Built-in Web Audio API)**: Memainkan progresi melodi romantis harmoni nada piano lembut tanpa butuh kuota atau hosting file eksternal (100% offline & anti-error).
   - **Mode Hujan & Piano**: Menghadirkan suasana hujan rintik-rintik yang menenangkan.
   - **Unggah Musik Sendiri**: Pasangan dapat memutar lagu kenangan pribadi (.mp3/.wav).
   - **Widget Piringan Hitam (*Vinyl Player*)**: Berputar dinamis lengkap dengan visualizer frekuensi nada audio.

3. **Untaian Kata Asmara yang Lengkap**:
   - **Prolog Pertemuan**: Menggambarkan betapa bersyukurnya saat semesta mempertemukan dua insan.
   - **Kartu Alasan Cinta**: Kartu interaktif berisi alasan mengapa hati terpaut selamanya.
   - **Galeri Foto Polaroid**: Menampilkan foto kenangan berbintang yang bisa langsung diganti dengan foto kalian berdua.
   - **Ikrar & Janji Suci**: Dilengkapi tombol **Mode Mesin Tik** yang mengetikkan kata per kata secara puitis.
   - **Bisikan Rahasia**: Kartu tersembunyi yang bisa diklik untuk membaca rahasia hati terdalam.
   - **Pertanyaan Hati (Interactive Proposal)**:
     - Tombol *"Ya, Selamanya Aku Mau! ❤️"* memicu selebrasi kembang api cinta dan melodi kemenangan cinta.
     - Tombol *"Tidak 🙈"* yang jahil dan akan otomatis melompat kabur saat didekati kursor/jari.

4. **Kalkulator Waktu Cinta (*Love Days Counter*)**:
   - Menghitung live hari, jam, menit, dan detik perjalanan cinta kalian.

5. **Kustomisasi & Tautan WhatsApp**:
   - Modal untuk mengubah nama penerima, pengirim, dan tanggal jadian.
   - Tombol **Salin Tautan WhatsApp** (`?to=Nama&from=Nama&date=YYYY-MM-DD`) untuk langsung dibagikan ke pasangan.
